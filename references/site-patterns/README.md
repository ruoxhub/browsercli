# 站点经验模板

此目录用于存储特定网站的操作经验和模式。

## 使用方法

1. 按域名创建文件：`{domain}.md`
2. 复制下面的模板内容
3. 填写已验证的经验

## 模板

```markdown
---
domain: example.com
aliases: [示例，Example]
updated: 2026-03-27
---

- 操作策略
- 选择器模式

## 已知陷阱
```
