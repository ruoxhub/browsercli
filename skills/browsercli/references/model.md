# 全量工具速查字典 (Complete Tool Index)

本项目目前共注册了 **113 个 MCP 工具**。下表提供工具名称到对应详细参考文档的快速映射：

| 模块分类                     | 参考文档路径                                    | 涵盖核心能力                                                            |
| :--------------------------- | :---------------------------------------------- | :---------------------------------------------------------------------- |
| **Browser & Navigation**     | [`references/browser.md`](./browser.md)         | 标签页导航、多 Frame/iframe 穿透、健康检查、设备与网络模拟、DevTools    |
| **Script & Source**          | [`references/script.md`](./script.md)           | 脚本收集、缓存正则检索、源码定位、预加载脚本注入                        |
| **Dynamic Hooks & Crypto**   | [`references/hook.md`](./hook.md)               | 非阻塞 Hook、CryptoJS/RSA/国密拦截、JSVMP 探针、环境对比                |
| **Debugger & Breakpoints**   | [`references/debugger.md`](./debugger.md)       | 行/条件/XHR断点、单步步进、作用域变量检查、日志点追踪、表达式执行       |
| **DOM & Interaction**        | [`references/dom.md`](./dom.md)                 | 多定位器查询、拟人化点击/打字、物理坐标点击、表单填充、样式分析、截屏   |
| **Network & WebSocket**      | [`references/network.md`](./network.md)         | 网络嗅探、**发起者调用栈追踪**、请求重放覆写、cURL 导出、WebSocket 聚类 |
| **Anti-Detection & Stealth** | [`references/stealth.md`](./stealth.md)         | 无限 debugger 绕过、反反调试防护罩、User-Agent 伪装、按需隐身预设       |
| **WebAssembly**              | [`references/wasm.md`](./wasm.md)               | Wasm 模块拦截导出、JS-Wasm 边界调用追踪、线性内存搜索                   |
| **Session & Storage**        | [`references/session.md`](./session.md)         | Cookie/Storage 导出、会话快照持久化备份与恢复、视频帧截取               |
| **Evidence & Diagnostics**   | [`references/evidence.md`](./evidence.md)       | 环境诊断、验证码探测                                                    |
| **Console Logs**             | [`references/console.md`](./console.md)         | 页面控制台日志消息列举、按 ID 结构化查询                                |
| **Performance**              | [`references/performance.md`](./performance.md) | CDP 性能轨迹录制、CWV 核心性能指标、性能瓶颈 Insight 分析               |
