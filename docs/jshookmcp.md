● 基于对 jshookmcp（402 工具/36 域/MCP 服务）和当前 JSReverser-CLI（~100 工具/前端 JS 逆向）的对比分析，以下是可引入功能的分级清单。

  项目对比定位

  ┌────────────┬───────────────────────────────────┬────────────────────────────┬────────────────────┐
  │    维度    │      JSReverser-CLI（当前）       │         jshookmcp          │        差距        │
  ├────────────┼───────────────────────────────────┼────────────────────────────┼────────────────────┤
  │ 定位       │ 前端 JS 逆向 + 标准化工作流       │ 全平台 JS/二进制安全研究   │ jshookmcp 范围更广 │
  ├────────────┼───────────────────────────────────┼────────────────────────────┼────────────────────┤
  │ 工具数     │ ~126                              │ 423                        │ 3 倍               │
  ├────────────┼───────────────────────────────────┼────────────────────────────┼────────────────────┤
  │ Profile    │ 静态 3 档（search/workflow/full） │ 同 3 档 + 动态激活         │ jshookmcp 更智能   │
  ├────────────┼───────────────────────────────────┼────────────────────────────┼────────────────────┤
  │ 网络层     │ CDP 监听（被动）                  │ CDP + MiTM + HTTP/2 + Burp │ 弱                 │
  ├────────────┼───────────────────────────────────┼────────────────────────────┼────────────────────┤
  │ 沙箱       │ 无                                │ QuickJS（128MB/5s）        │ 缺失               │
  ├────────────┼───────────────────────────────────┼────────────────────────────┼────────────────────┤
  │ 工具搜索   │ 单一 search 工具                  │ BM25+向量+RRF 混合         │ 弱                 │
  ├────────────┼───────────────────────────────────┼────────────────────────────┼────────────────────┤
  │ Native FFI │ 无                                │ 33 文件（内存/PE/HBP）     │ 不匹配定位         │
  └────────────┴───────────────────────────────────┴────────────────────────────┴────────────────────┘

  强烈推荐引入（高 ROI，匹配前端 JS 逆向定位）

  1. 搜索引擎升级 ⭐⭐⭐⭐⭐

  ▎ 来源：src/server/search/（BM25Scorer + EmbeddingEngine + AffinityGraph + RRF 融合）

  当前痛点：JSReverser 的 search profile 只暴露一个 search_tools，AI 在 100+ 工具中靠关键词找工具，命中率低。

  建议引入：
  - BM25Scorer 倒排索引（无依赖，纯 TS 实现）
  - TrigramIndex 模糊匹配（Jaccard）
  - RRF 多信号融合
  - 可选：EmbeddingEngine（依赖 @huggingface/transformers，体积大，列为 optional）

  引入成本：低（纯算法，无运行时副作用），3-5 天

  ---
  2. 大响应卸载机制 ⭐⭐⭐⭐⭐

  ▎ 来源：src/server/ToolResponseOffloader.ts + src/utils/DetailedDataManager.ts

  当前痛点：JSReverser 工具返回大量代码/网络数据时直接塞进 MCP 响应，token 爆炸。已有 TokenBudgetManager 但只做记账不做卸载。

  建议引入：
  - 响应 >512KB 自动落盘
  - 返回 artifact_id 让 AI 按需读取
  - AdaptiveDataSerializer 7 种类型自适应

  引入成本：中（需改造工具响应通道），1 周

  ---
  3. MCP 元工具能力 ⭐⭐⭐⭐

  ▎ 来源：MCPServer.search.ts + ToolRouter.ts

  当前痛点：generated-tools-index.ts 仅提供工具列表，无法让 AI 自助探索参数细节、覆盖率。

  建议引入：
  - describe_tool(name) 返回 schema + 示例 + 前置依赖
  - search_tools(query, intent) 智能推荐 + 激活建议
  - coverage_report() 显示哪些域已激活/调用过

  引入成本：低，2-3 天（已有 ToolRegistry 基础）

  ---
  4. MiTM 代理 + HTTP/2 拦截 ⭐⭐⭐⭐

  ▎ 来源：src/server/domains/proxy/ + mockttp 库

  当前痛点：JSReverser 的 network 工具只能监听 CDP 事件，无法主动篡改请求。逆向时常需要重放、改包、签名验证。

  建议引入：
  - proxy_start / proxy_stop（自动生成本地 HTTPS CA）
  - 请求拦截规则
  - HAR 录制/回放

  引入成本：中，1-2 周（mockttp 是 npm 包，集成即可）

  ---
  5. QuickJS 沙箱执行 ⭐⭐⭐⭐

  ▎ 来源：src/server/sandbox/QuickJSSandbox.ts + quickjs-emscripten

  当前痛点：JSReverser 反混淆后的代码要本地复现验证，目前依赖 export_rebuild_bundle + 手动 node entry.js。沙箱可在 Worker 内直接试跑可疑片段。

  建议引入：
  - 内存/超时限制的 JS 执行
  - 用于：反混淆结果验证、加密算法提纯后的纯函数测试、env 缺失探测

  引入成本：低（quickjs-emscripten 即装即用），3-5 天

  ---
  6. 错误分类 + 滑动窗口降级 ⭐⭐⭐

  ▎ 来源：src/errors/ToolError.ts

  当前痛点：JSReverser 已有 ToolError，但分类粗糙、无降级。

  建议引入：
  - 7 类错误码：PREREQUISITE / VALIDATION / NOT_FOUND / TIMEOUT / CONNECTION / RUNTIME / PERMISSION
  - 60s 窗口 ≥8 错误进入降级（关 token 跟踪/降日志级别）
  - 致命错误（OOM/EMFILE）直接退出

  引入成本：低（增量改造现有 errors.ts），2-3 天

  ---
  中等价值（按需引入）

  7. 扩展 SDK + 工作流 DAG

  ▎ 来源：packages/extension-sdk/

  让用户/AI 用流式 API 定义工作流：
  workflow().sequence([
    tool('list_scripts'),
    parallel([tool('detect_crypto'), tool('deobfuscate_code')]),
    fallback([tool('hook_function'), tool('set_breakpoint')])
  ])
  对应 JSReverser 的 workflow/ 工具集，可大幅强化。

  引入成本：中，1 周

  ---
  8. 事件驱动域激活（替代静态 Profile）

  ▎ 来源：src/server/activation/ActivationController.ts

  当 browser:launched 事件触发时自动激活 network 域；不活动 5 分钟自动 prune。比静态 JS_REVERSE_TOOL_PROFILE=full 更省 token。

  引入成本：中（依赖 EventBus 改造，JSReverser 已有 EventBus 基础），1 周

  ---
  9. Camoufox 反检测浏览器

  ▎ 来源：camoufox-js（optionalDependency）

  JSReverser 现有 stealth-args.ts 仅 60 项启动参数，对抗强反爬不够。Camoufox 是 Firefox fork，深度反检测。

  引入成本：低（作为 BrowserManager 的可选引擎），3 天

  ---
  10. Frida 桥接

  ▎ 来源：src/server/domains/binary-instrument/

  仅当用户的逆向场景涉及 Native（如 Electron、桌面 Web、APP WebView）时有价值。

  引入成本：高（依赖外部 Frida 进程），2 周
