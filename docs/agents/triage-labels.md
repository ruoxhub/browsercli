# 分诊标签（Triage Labels）

这些 skill 用五个规范的分诊角色来说话。这个文件把那些角色映射到本仓库 issue 跟踪器里实际使用的标签字符串。

| mattpocock/skills 中的标签 | 我们跟踪器中的标签 | 含义                         |
| -------------------------- | ------------------ | ---------------------------- |
| `needs-triage`             | `needs-triage`     | 维护者需要评估这个 issue     |
| `needs-info`               | `needs-info`       | 等待报告者提供更多信息       |
| `ready-for-agent`          | `ready-for-agent`  | 已完整说明，可用于 AFK agent |
| `ready-for-human`          | `ready-for-human`  | 需要人来实现                 |
| `wontfix`                  | `wontfix`          | 不会处理                     |

当一个 skill 提到某个角色（例如"打上 AFK 就绪的分诊标签"）时，使用这张表里对应的标签字符串。

编辑"我们跟踪器中的标签"一列，以匹配你实际使用的词表。
