## Types

### <a name="touchpoint"></a>TouchPoint

* **Type**: `object`
* **Properties**:

| Name | Type | Description |
| --- | --- | --- |
| `x` | `number` | X coordinate of the event relative to the main frame's viewport in CSS pixels. |
| `y` | `number` | Y coordinate of the event relative to the main frame's viewport in CSS pixels. 0 refers to<br/>the top of the viewport and Y increases as it proceeds towards the bottom of the viewport. |
| `radiusX`<br/>_optional_ | `number` | X radius of the touch area (default: 1.0). |
| `radiusY`<br/>_optional_ | `number` | Y radius of the touch area (default: 1.0). |
| `rotationAngle`<br/>_optional_ | `number` | Rotation angle (default: 0.0). |
| `force`<br/>_optional_ | `number` | Force (default: 1.0). |
| `tangentialPressure`<br/>_optional_ | `number` | `🧪 experimental` The normalized tangential pressure, which has a range of [-1,1] (default: 0). |
| `tiltX`<br/>_optional_ | `number` | The plane angle between the Y-Z plane and the plane containing both the stylus axis and the Y axis, in degrees of the range [-90,90], a positive tiltX is to the right (default: 0) |
| `tiltY`<br/>_optional_ | `number` | The plane angle between the X-Z plane and the plane containing both the stylus axis and the X axis, in degrees of the range [-90,90], a positive tiltY is towards the user (default: 0). |
| `twist`<br/>_optional_ | `integer` | `🧪 experimental` The clockwise rotation of a pen stylus around its own major axis, in degrees in the range [0,359] (default: 0). |
| `id`<br/>_optional_ | `number` | Identifier used to track touch sources between events, must be unique within an event. |


### <a name="gesturesourcetype"></a>GestureSourceType `🧪 experimental`

* **Type**: `string`
* **Allowed values**: `"default"`, `"touch"`, `"mouse"`

### <a name="mousebutton"></a>MouseButton

* **Type**: `string`
* **Allowed values**: `"none"`, `"left"`, `"middle"`, `"right"`, `"back"`, `"forward"`

### <a name="timesinceepoch"></a>TimeSinceEpoch

UTC time in seconds, counted from January 1, 1970.

* **Type**: `number`

### <a name="dragdataitem"></a>DragDataItem `🧪 experimental`

* **Type**: `object`
* **Properties**:

| Name | Type | Description |
| --- | --- | --- |
| `mimeType` | `string` | Mime type of the dragged data. |
| `data` | `string` | Depending of the value of `mimeType`, it contains the dragged link,<br/>text, HTML markup or any other data. |
| `title`<br/>_optional_ | `string` | Title associated with a link. Only valid when `mimeType` == "text/uri-list". |
| `baseURL`<br/>_optional_ | `string` | Stores the base URL for the contained markup. Only valid when `mimeType`<br/>== "text/html". |


### <a name="dragdata"></a>DragData `🧪 experimental`

* **Type**: `object`
* **Properties**:

| Name | Type | Description |
| --- | --- | --- |
| `items` | array of [DragDataItem](#dragdataitem) |  |
| `files`<br/>_optional_ | array of `string` | List of filenames that should be included when dropping |
| `dragOperationsMask` | `integer` | Bit field representing allowed drag operations. Copy = 1, Link = 2, Move = 16 |

## Commands

### <a name="dispatchdragevent"></a>dispatchDragEvent `🧪 experimental`

Dispatches a drag event into the page.

* **Parameters**:

| Name | Type | Description |
| --- | --- | --- |
| `type` | `string` | Type of the drag event.<br/>Allowed values: `"dragEnter"`, `"dragOver"`, `"drop"`, `"dragCancel"` |
| `x` | `number` | X coordinate of the event relative to the main frame's viewport in CSS pixels. |
| `y` | `number` | Y coordinate of the event relative to the main frame's viewport in CSS pixels. 0 refers to<br/>the top of the viewport and Y increases as it proceeds towards the bottom of the viewport. |
| `data` | [DragData](#dragdata) |  |
| `modifiers`<br/>_optional_ | `integer` | Bit field representing pressed modifier keys. Alt=1, Ctrl=2, Meta/Command=4, Shift=8<br/>(default: 0). |

* **Returns**: None


### <a name="dispatchkeyevent"></a>dispatchKeyEvent

Dispatches a key event to the page.

* **Parameters**:

| Name | Type | Description |
| --- | --- | --- |
| `type` | `string` | Type of the key event.<br/>Allowed values: `"keyDown"`, `"keyUp"`, `"rawKeyDown"`, `"char"` |
| `modifiers`<br/>_optional_ | `integer` | Bit field representing pressed modifier keys. Alt=1, Ctrl=2, Meta/Command=4, Shift=8<br/>(default: 0). |
| `timestamp`<br/>_optional_ | [TimeSinceEpoch](#timesinceepoch) | Time at which the event occurred. |
| `text`<br/>_optional_ | `string` | Text as generated by processing a virtual key code with a keyboard layout. Not needed for<br/>for `keyUp` and `rawKeyDown` events (default: "") |
| `unmodifiedText`<br/>_optional_ | `string` | Text that would have been generated by the keyboard if no modifiers were pressed (except for<br/>shift). Useful for shortcut (accelerator) key handling (default: ""). |
| `keyIdentifier`<br/>_optional_ | `string` | Unique key identifier (e.g., 'U+0041') (default: ""). |
| `code`<br/>_optional_ | `string` | Unique DOM defined string value for each physical key (e.g., 'KeyA') (default: ""). |
| `key`<br/>_optional_ | `string` | Unique DOM defined string value describing the meaning of the key in the context of active<br/>modifiers, keyboard layout, etc (e.g., 'AltGr') (default: ""). |
| `windowsVirtualKeyCode`<br/>_optional_ | `integer` | Windows virtual key code (default: 0). |
| `nativeVirtualKeyCode`<br/>_optional_ | `integer` | Native virtual key code (default: 0). |
| `autoRepeat`<br/>_optional_ | `boolean` | Whether the event was generated from auto repeat (default: false). |
| `isKeypad`<br/>_optional_ | `boolean` | Whether the event was generated from the keypad (default: false). |
| `isSystemKey`<br/>_optional_ | `boolean` | Whether the event was a system key event (default: false). |
| `location`<br/>_optional_ | `integer` | Whether the event was from the left or right side of the keyboard. 1=Left, 2=Right (default:<br/>0). |
| `commands`<br/>_optional_ | array of `string` | `🧪 experimental` Editing commands to send with the key event (e.g., 'selectAll') (default: []).<br/>These are related to but not equal the command names used in `document.execCommand` and NSStandardKeyBindingResponding.<br/>See https://source.chromium.org/chromium/chromium/src/+/main:third_party/blink/renderer/core/editing/commands/editor_command_names.h for valid command names. |

* **Returns**: None


### <a name="inserttext"></a>insertText `🧪 experimental`

for example an emoji keyboard or an IME.

* **Parameters**:

| Name | Type | Description |
| --- | --- | --- |
| `text` | `string` | The text to insert. |

* **Returns**: None


### <a name="imesetcomposition"></a>imeSetComposition `🧪 experimental`

This method sets the current candidate text for IME.
Use imeCommitComposition to commit the final text.
Use imeSetComposition with empty string as text to cancel composition.

* **Parameters**:

| Name | Type | Description |
| --- | --- | --- |
| `text` | `string` | The text to insert |
| `selectionStart` | `integer` | selection start |
| `selectionEnd` | `integer` | selection end |
| `replacementStart`<br/>_optional_ | `integer` | replacement start |
| `replacementEnd`<br/>_optional_ | `integer` | replacement end |

* **Returns**: None


### <a name="dispatchmouseevent"></a>dispatchMouseEvent

Dispatches a mouse event to the page.

* **Parameters**:

| Name | Type | Description |
| --- | --- | --- |
| `type` | `string` | Type of the mouse event.<br/>Allowed values: `"mousePressed"`, `"mouseReleased"`, `"mouseMoved"`, `"mouseWheel"` |
| `x` | `number` | X coordinate of the event relative to the main frame's viewport in CSS pixels. |
| `y` | `number` | Y coordinate of the event relative to the main frame's viewport in CSS pixels. 0 refers to<br/>the top of the viewport and Y increases as it proceeds towards the bottom of the viewport. |
| `modifiers`<br/>_optional_ | `integer` | Bit field representing pressed modifier keys. Alt=1, Ctrl=2, Meta/Command=4, Shift=8<br/>(default: 0). |
| `timestamp`<br/>_optional_ | [TimeSinceEpoch](#timesinceepoch) | Time at which the event occurred. |
| `button`<br/>_optional_ | [MouseButton](#mousebutton) | Mouse button (default: "none"). |
| `buttons`<br/>_optional_ | `integer` | A number indicating which buttons are pressed on the mouse when a mouse event is triggered.<br/>Left=1, Right=2, Middle=4, Back=8, Forward=16, None=0. |
| `clickCount`<br/>_optional_ | `integer` | Number of times the mouse button was clicked (default: 0). |
| `force`<br/>_optional_ | `number` | `🧪 experimental` The normalized pressure, which has a range of [0,1] (default: 0). |
| `tangentialPressure`<br/>_optional_ | `number` | `🧪 experimental` The normalized tangential pressure, which has a range of [-1,1] (default: 0). |
| `tiltX`<br/>_optional_ | `number` | The plane angle between the Y-Z plane and the plane containing both the stylus axis and the Y axis, in degrees of the range [-90,90], a positive tiltX is to the right (default: 0). |
| `tiltY`<br/>_optional_ | `number` | The plane angle between the X-Z plane and the plane containing both the stylus axis and the X axis, in degrees of the range [-90,90], a positive tiltY is towards the user (default: 0). |
| `twist`<br/>_optional_ | `integer` | `🧪 experimental` The clockwise rotation of a pen stylus around its own major axis, in degrees in the range [0,359] (default: 0). |
| `deltaX`<br/>_optional_ | `number` | X delta in CSS pixels for mouse wheel event (default: 0). |
| `deltaY`<br/>_optional_ | `number` | Y delta in CSS pixels for mouse wheel event (default: 0). |
| `pointerType`<br/>_optional_ | `string` | Pointer type (default: "mouse").<br/>Allowed values: `"mouse"`, `"pen"` |

* **Returns**: None


### <a name="dispatchtouchevent"></a>dispatchTouchEvent

Dispatches a touch event to the page.

* **Parameters**:

| Name | Type | Description |
| --- | --- | --- |
| `type` | `string` | Type of the touch event. TouchEnd and TouchCancel must not contain any touch points, while<br/>TouchStart and TouchMove must contains at least one.<br/>Allowed values: `"touchStart"`, `"touchEnd"`, `"touchMove"`, `"touchCancel"` |
| `touchPoints` | array of [TouchPoint](#touchpoint) | Active touch points on the touch device. One event per any changed point (compared to<br/>previous touch event in a sequence) is generated, emulating pressing/moving/releasing points<br/>one by one. |
| `modifiers`<br/>_optional_ | `integer` | Bit field representing pressed modifier keys. Alt=1, Ctrl=2, Meta/Command=4, Shift=8<br/>(default: 0). |
| `timestamp`<br/>_optional_ | [TimeSinceEpoch](#timesinceepoch) | Time at which the event occurred. |

* **Returns**: None

### <a name="emulatetouchfrommouseevent"></a>emulateTouchFromMouseEvent `🧪 experimental`

| `clickCount`<br/>_optional_ | `integer` | Number of times the mouse button was clicked (default: 0). |

### <a name="synthesizepinchgesture"></a>synthesizePinchGesture `🧪 experimental`

Synthesizes a pinch gesture over a time period by issuing appropriate touch events.

* **Parameters**:

| Name | Type | Description |
| --- | --- | --- |
| `x` | `number` | X coordinate of the start of the gesture in CSS pixels. |
| `y` | `number` | Y coordinate of the start of the gesture in CSS pixels. |
| `scaleFactor` | `number` | Relative scale factor after zooming (>1.0 zooms in, <1.0 zooms out). |
| `relativeSpeed`<br/>_optional_ | `integer` | Relative pointer speed in pixels per second (default: 800). |
| `gestureSourceType`<br/>_optional_ | [GestureSourceType](#gesturesourcetype) | Which type of input events to be generated (default: 'default', which queries the platform<br/>for the preferred input type). |

* **Returns**: None


### <a name="synthesizescrollgesture"></a>synthesizeScrollGesture `🧪 experimental`

Synthesizes a scroll gesture over a time period by issuing appropriate touch events.

* **Parameters**:

| Name | Type | Description |
| --- | --- | --- |
| `x` | `number` | X coordinate of the start of the gesture in CSS pixels. |
| `y` | `number` | Y coordinate of the start of the gesture in CSS pixels. |
| `xDistance`<br/>_optional_ | `number` | The distance to scroll along the X axis (positive to scroll left). |
| `yDistance`<br/>_optional_ | `number` | The distance to scroll along the Y axis (positive to scroll up). |
| `xOverscroll`<br/>_optional_ | `number` | The number of additional pixels to scroll back along the X axis, in addition to the given<br/>distance. |
| `yOverscroll`<br/>_optional_ | `number` | The number of additional pixels to scroll back along the Y axis, in addition to the given<br/>distance. |
| `preventFling`<br/>_optional_ | `boolean` | Prevent fling (default: true). |
| `speed`<br/>_optional_ | `integer` | Swipe speed in pixels per second (default: 800). |
| `gestureSourceType`<br/>_optional_ | [GestureSourceType](#gesturesourcetype) | Which type of input events to be generated (default: 'default', which queries the platform<br/>for the preferred input type). |
| `repeatCount`<br/>_optional_ | `integer` | The number of times to repeat the gesture (default: 0). |
| `repeatDelayMs`<br/>_optional_ | `integer` | The number of milliseconds delay between each repeat. (default: 250). |
| `interactionMarkerName`<br/>_optional_ | `string` | The name of the interaction markers to generate, if not empty (default: ""). |

* **Returns**: None
